# Mataroa Telegram Bot

A Telegram bot for managing posts on Mataroa.blog from chat.

It can:
- create new posts
- save drafts and resume drafts
- update existing posts
- delete posts with an undo window
- list and search posts
- toggle publish state
- show API connectivity status

Get a Mataroa API key here:
https://mataroa.blog/api/docs/

Environment:
- `BOT_TOKEN` is required.
- `MATAROA_BOT_DIR` optionally sets the private state directory.
- `MATAROA_BOT_ALLOWED_USERS` optionally restricts the bot to comma-separated Telegram user IDs.
